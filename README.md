# Cadence 创作工作台

本地科普文章 → 统一风格图文或视频讲解页。9:16 用于小红书图文，不生成口播稿；16:9 用于视频画面，附逐页口播稿。前后端分为两个项目文件夹：`backend`（Python / FastAPI）与 `frontend`（React / TypeScript / Vite）。

## 本地启动

需要 Python 3.11+（推荐 3.12）、uv、Node.js 20+。在两个终端分别运行：

```powershell
cd backend
uv sync
Copy-Item .env.example .env
# 编辑 .env，填写 OPENAI_API_KEY 与 OPENAI_MODEL
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

`.env` 只需首次复制，已有配置时不要覆盖。生成前需配置可用的模型和密钥。

```powershell
cd frontend
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。API 文档位于 http://127.0.0.1:8000/docs 。前端通过 Vite 代理访问后端。

依赖安装后，也可以分别双击根目录的 `start-backend.cmd` 和 `start-frontend.cmd` 启动。

后端需要正常的外网访问权限。由助手启动时应使用允许联网的运行环境；受限沙箱中的后端即使健康检查正常，也可能无法调用模型。遇到“联网权限被拒绝”，先停止该后端，再从普通终端或双击 `start-backend.cmd` 启动（不需要管理员权限）。连接测试失败的异常类型和数值错误码保存在 `backend/data/diagnostics/connection-*.json`，不保存密钥或上游错误原文。连接测试成功仅验证基础调用，不代表完整文章生成已通过。

## 使用

1. 粘贴科普文章，选择「9:16 小红书图文」或「16:9 视频讲解」。
2. 在「模型设置」填写 API Key、可用的模型 ID 和 Base URL。密钥输入隐藏，保存在本机 `backend/.env`，不回传前端；留空保留原密钥，输入新值则替换。也可手动编辑 `.env`。
3. 粘贴 100–20,000 字文章，选择生成格式，然后生成。模型需要支持 Chat Completions 的 `json_schema` 结构化输出。
4. 选择页面，编辑标题、正文、重点和口播稿，保存当前页。也可输入修改指示重新生成该页。
5. 下载当前页 PNG 图片、导出离线网页或备份项目；视频模式还可导出 Markdown 口播稿。图片目标分辨率为竖版 1080×1920、横版 1920×1080。视频模式提供画面和口播文字，不直接编码视频文件。导出前会保存当前修改。HTML 无外部资源，可离线浏览和打印。

项目保存在 `backend/data/projects`，界面不再显示最近项目列表，请及时导出备份。JSON 导出用于备份，本版尚无 JSON 导入。任务状态保存在 `backend/data/jobs`；页面刷新或重新打开后始终从空白画布开始，不恢复旧项目或任务；生成中请保持页面打开。后端重启时未完成任务会标记失败并提示重试。服务仅面向本地单进程使用，不启动多个 worker。

原文不持久化，但真实生成时会发往你配置的模型服务。失败输出保存在 `backend/data/diagnostics` 供调试，其中可能包含文章片段。密钥不返回前端，也不写入导出文件。

```powershell
cd backend
uv run pytest
```

```powershell

```

## 实现说明

- 先按 Pydantic JSON Schema 规划大纲，再逐页调用模型生成内容；大纲、页面内容或口播长度不合格时修订一次。逐页调用会增加模型请求数量。
- 生成进度面板显示规划、逐页生成、校验和保存阶段，以及总页数、当前页、已完成页数、各阶段与每页耗时。页数在大纲返回前显示待确定，进度条只统计已完成页面，不估算模型内部进度。后端持久化时间戳，前端每秒读取进度并计时；当前页面断线自动重连，刷新不恢复任务，失败时保留中断位置。
- 页数按模型判断，在首期设为 4–12 页；口播时长由字数和语速估算。
- 预览和导出使用同一版本的卡片 CSS。后端 `app/templates/deck.css` 为源文件，改动后同步到 `frontend/src/deck.css`。
- 无图片生成、联网检索、配音或视频导出。视觉以排版和重点节点为主，视觉建议作为编辑字段保留。
- 首期仅实现自然科普主题。没有背景自动保存，修改后请点击保存。

OpenAI 接入参考：[结构化输出官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)。完整产品边界见 [开发设计](docs/MVP-开发设计.md)。

模型请求：生成大纲、逐页生成和单页重写的响应等待上限为 600 秒，建立连接上限为 20 秒；连接测试的响应等待上限为 90 秒。使用流式结构化输出；网络中断时仅重试当前请求一次并显示状态，不重做已完成页面。每个请求连同网络重试总计最多 600 秒；内容校验失败仍修复一次。Vite 代理允许单页重写及一次内容修复的较长请求。延长等待不会加快模型本身的生成速度。

画布使用主题图标、分段正文和重点卡片；封面为深绿底，总结与行动页使用暖色标记。预览、PNG 和离线 HTML 共用卡片样式与图标。生成提示要求正文 60–110 字、短段落和带小标题的重点，旧项目无需重新生成也可应用新版排版。结构校验是本地格式校验，不代表事实核查；不足一秒的已完成阶段显示“少于 1 秒”，完成后保留最后处理页及该页耗时。

连接诊断保存异常类型链与数值错误码，不保存异常消息中的密钥或请求地址。基础连接测试只代表短请求可用，不保证完整生成期间网络持续可用。

如果国内模型接口经过本机代理时出现 TLS 中断，可在 `backend/.env` 设置 `CADENCE_USE_SYSTEM_PROXY=false` 并重启后端，让本项目模型请求直连。默认 `true` 沿用系统/环境代理；此开关不修改系统代理设置。
